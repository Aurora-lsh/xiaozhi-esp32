# 摄像头与桥接动态地址

ESP32 和桥接电脑都可能更换 IP。摄像头主动向电脑注册自身 IP，电脑地址可通过串口配置并保存在 NVS。

注册接口为 POST /camera/register，请求头 X-Camera-Key 与服务端固定 key 比较，请求 JSON 为 {"ip":"192.168.1.20"}。成功返回 200；鉴权失败 403；无效格式或 IPv4 地址 400；超过 1024 字节 413；地址保存失败 503。认证失败不改变已注册地址。

桥接监听与小智 WebSocket 生命周期分离，网络重连时保持监听。MCP 子进程和父进程状态回传均读取原子写入的 runtime/camera_address.json，下一次请求直接使用最新地址。地址在桥接重启后保留，key 更换后旧记录失效。未注册且无兼容地址时，MCP 返回等待设备上报的说明。

固件独立任务联网/IP 变化后上报，失败 5 秒重试，成功 60 秒重报。任务栈为 4096 字节，连接与读取超时各 1.5 秒。请求不包含模型 API key。

串口命令 mcp_ip=IPv4 校验后保存到 wifi NVS 命名空间的 bridge_ip，mcp_ip? 查询待应用值；reboot 后应用，与既有 Wi-Fi 设置方式一致。固定 key 与端口保持在私有编译配置。默认桥接 IP 仅作为未保存设置时的初始值。

临时记录、缓存及编译产物归入 temporary，编译和烧录脚本同步更新。私有配置与归档目录加入忽略规则。
