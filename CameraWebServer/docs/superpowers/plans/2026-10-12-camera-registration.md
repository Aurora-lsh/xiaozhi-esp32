# 摄像头动态地址注册

用户明确要求实现固定 key 的主动地址上报，并整理临时文件。

1. 独立 HTTP 注册服务，限制请求长度，校验 key 和 IPv4 地址。
2. 原子保存地址，MCP 子进程和状态回传实时读取；保留手动地址兼容。
3. ESP32 在摄像头服务启动后创建上报任务，联网/IP 变化时上报，失败重试，定期重报。
4. 验证鉴权、无效请求、地址变化、跨进程读取与固件上报调度。
5. 将临时计划、缓存和编译产物归档到 temporary，更新脚本和文档。
6. 运行电脑端、固件宿主测试及 ESP32-CAM 编译，不烧录硬件。

补充需求：桥接电脑 IP 通过串口 mcp_ip=IPv4 修改，NVS 保存，mcp_ip? 查询，reboot 后应用。
复核修复：开机联网超时后延迟启动服务；返回网页链接使用最新地址；注册接口限制 4 个并发连接和 3 秒总时限。

协议：POST /camera/register，X-Camera-Key 请求头，JSON {"ip":"192.168.1.20"}。
默认监听 0.0.0.0:8765；共享状态位于 mcp_server/runtime/camera_address.json。
上报使用局域网 HTTP，key 仅在两端私有配置中保存，不进入日志或地址状态文件。

全部实施步骤已完成。最终验证：电脑端 30 项测试、串口/初始化宿主 33 项测试、上报调度 12 项检查通过；ESP32-CAM Core 2.0.14 编译通过，BIN 注册和串口功能字符串及 key 校验通过。未进行硬件烧录。
